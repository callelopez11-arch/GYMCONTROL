# GYMCONTROL

## Sistema de administración de gimnasios

GYMCONTROL es una aplicación web desarrollada como proyecto formativo del programa Tecnólogo en Análisis y Desarrollo de Software del SENA. Su propósito es facilitar la gestión y administración de la información básica de un gimnasio mediante una interfaz sencilla e intuitiva.

## Objetivo del proyecto

Desarrollar una aplicación web que permita organizar y consultar información relacionada con los usuarios, rutinas de entrenamiento, mensualidades, pagos e inscripciones a concursos.

## Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: diseño y estilos de la interfaz.
- JavaScript: funcionalidades y lógica del sistema.
- localStorage: almacenamiento local de los registros.
- sessionStorage: gestión temporal de la sesión.

## Módulos del sistema

1. Inicio de sesión.
2. Panel principal.
3. Gestión de usuarios.
4. Programación de rutinas.
5. Historial de rutinas.
6. Administración de mensualidades.
7. Historial de pagos.
8. Gestión de concursos.
9. Ajustes y restauración de datos de demostración.

## Estructura del proyecto

- `index.html`: pantalla de inicio de sesión.
- `home.html`: panel principal y módulos.
- `script.js`: funcionalidades y lógica de la aplicación.
- `styles.css`: estilos y diseño visual.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Ubicar los archivos del proyecto en una misma carpeta.
3. Abrir el archivo `index.html` desde un navegador web.
4. Ingresar con las credenciales de demostración configuradas en la aplicación.

## Alcance técnico

GYMCONTROL corresponde a una aplicación frontend de ejecución local. Los datos se almacenan en el navegador mediante localStorage y sessionStorage.

Esta versión no implementa backend, API ni base de datos SQL. La información no se sincroniza entre diferentes dispositivos.
